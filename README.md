# XIUI+

> **Super early version:** Expect bugs. Profile importing may not work properly.

## Install

1. [Download XIUIplus.dll (0.1.0-alpha.2)](https://github.com/Shuu-37/xiuiplus-releases/releases/download/v0.1.0-alpha.2/XIUIplus.dll).
2. Put it in your Ashita `plugins` folder.
3. In game, type `/load XIUIplus`.
4. Type `/xiuip edit` to open settings and move your HUD.

## Basic commands

- `/xiuip edit` — Toggle edit mode and settings.
- `/xiuip save` — Save your settings.
- `/xiuip show` / `/xiuip hide` — Show or hide the HUD.
- `/xiuip help` — Show command help.
- `/unload XIUIplus` — Unload the plugin.
